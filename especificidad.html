Estructura y Sintaxis Niveles de Especificidad Pseudo Clases y Elementos Box Model

¿Qué es la Especificidad?

Sistema que usa el navegador para resolver conflictos cuando varias reglas CSS apuntan al mismo elemento.

Fórmula: [ Inline, ID, Clase, Etiqueta ]

Contador de 4 dígitos: (0, 0, 0, 0)

Nivel 1: Etiquetas (1 Pt)

Selectores más débiles. Afectan a la etiqueta directamente o a fragmentos específicos.

Ejemplos:

h1, p, div, ::before, ::after

Nivel 2: Clases (10 Pts)

Selección por grupos, estados o atributos HTML.

Ejemplos:

.mi-clase, :hover, :focus, [type="text"]

Nivel 3: Identificadores / IDs (100 Pts)

Selectores únicos de alta prioridad.

Ejemplos:

#header, #btn-submit, #modal-principal

Nivel 4: Inline (1000 Pts)

Estilos escritos en la etiqueta HTML mediante el atributo style="".

<p style="color: red;">

Peso Cero (0 Pts)

Elementos que afectan el flujo pero no suman puntos.

* (Universal)
>, +, ~, :where()

Cascada y Pseudo-clases

Desempate: A igual puntaje, gana la regla escrita al final.

:is(), :not(), :has(): Toman los puntos del selector más fuerte dentro de su paréntesis.

:is(h1, #titulo) = 100 pts

Excepción: !important

Comodín que rompe la cascada y la especificidad normal.

color: red !important;

Advertencia: Evitar en código limpio; usar solo en casos extremos.
