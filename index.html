1. Estructura y Sintaxis

Es la forma en que le damos órdenes al navegador para que ponga las cosas bonitas. Funciona con reglas:

  • Selector: A quién le aplicamos el cambio (ej. h1, p, .clase).
  • Llaves { }: Adentro va nuestro bloque de código.
  • Propiedad y Valor: Lo que cambiamos y cómo queda (ej. color: red;).

2. Niveles de Especificidad

Cuando dos estilos pelean, el navegador usa puntos para decidir quién gana:

  1. Etiquetas (p, div): Más débiles (1 punto).
  2. Clases (.boton): Ganan a etiquetas (10 puntos).
  3. IDs (#menu): Pesos pesados (100 puntos).
  4. En línea (style=""): Casi siempre ganan (1000 puntos).

3. Pseudo-clases (:)

Son para cuando el elemento cambia de estado:

  • :hover (cuando le pasas el mouse por encima).
  • :active (para cuando le das clic).

Pseudo-elementos (::)

Modifican solo una partecita o inyectan contenido:

  • ::before (agrega cosas antes).
  • ::after (agrega cosas después).
