¿Qué es una pseudoclase CSS?

Las pseudoclases se utilizan para hacer referencia a elementos HTML que tengan un cierto comportamiento concreto. Volvamos a recordar el esquema general de sintaxis de CSS, donde ahora añadiremos las pseudoclases, que se definen añadiendo dos puntos antes del nombre de la pseudoclase concreta, de la siguiente forma:

:hover

Se activa cuando el usuario pasa el puntero del mouse sobre un elemento.

:active

Se aplica en el instante exacto en que un elemento es cliqueado o presionado.

:focus

Se activa cuando el elemento recibe el foco (tecla Tab o clic en un campo).

:focus-within

Se aplica a un contenedor si él mismo o cualquiera de sus hijos tiene el foco.

:visited

Aplica estilos a enlaces que el navegador registra como ya visitados.

:target

Selecciona el elemento cuyo id coincide con el ancla (#id) actual en la URL.
